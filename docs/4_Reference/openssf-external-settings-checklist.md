# OpenSSF External Settings Checklist

The repository-owned OpenSSF work is complete. The following remain human/provider actions rather than an active
implementation programme:

- review branch protection and required-check settings on the remote hosting provider;
- confirm security-policy and vulnerability-reporting links render as intended;
- review any scorecard recommendations that require organisation-owner permissions;
- record completion only from provider-visible evidence.

This checklist does not authorize remote settings changes or external communication.

## Separate external submission choice

The completed Memory Index dry run produced a private benchmark result. Whether to submit it to an
external benchmark remains a user decision. The completed experiment does not itself authorize a
submission, disclosure, account action, or communication.
