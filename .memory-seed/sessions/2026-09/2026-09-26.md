  - Scope: `memory_seed/retrieval.py` worker batch rendering and measurement.
  - Disposition: Implemented.

  - Disposition: Implemented.
- R: The rubric tells workers to name an ordinal only on a 2+-decision end, but the validator rejected the null it produces. That contradiction rejected 193 of 207 correct rows in one run.
- F: `memory_seed/retrieval.py`, `tests/test_link_autoclassify.py`.
- T: A new test covers null ordinals and a reason-only `none`; re-collecting the same findings raised validity from 5 survivors to 206 of 207 valid rows.
