#### D2 - Decision: Write swarm batch payloads one pair per line
- D: A worker batch's assignment JSON puts each candidate pair on its own line; the size arithmetic counts the extra line breaks exactly.
  - Scope: `memory_seed/retrieval.py` worker batch rendering and measurement.
  - Disposition: Implemented.
- R: The whole payload sat on one line of about 43k tokens, beyond what an agent's file reader can page to. Workers could not read the pairs at all, and the Haiku run fell back to guessing verdicts with keyword scripts.
- F: `memory_seed/retrieval.py`, `tests/test_link_audit.py`.
- T: The batch test now asserts that no line exceeds 4000 characters. A real 11-batch plan's longest line is about 11k characters, and it materialized with exact byte measurement.
