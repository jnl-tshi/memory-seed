#### D1 - Separate agent effort from replaceable GPU execution

- D: The harness records unioned `agent_active`, `compute_wait`, `treatment_setup`, and derived end-to-end intervals; GPU identity and duration remain diagnostic, while solution quality and active agent effort drive comparisons.
