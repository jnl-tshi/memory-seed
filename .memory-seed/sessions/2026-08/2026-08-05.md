### Decisions

#### D1 - Read the index as substrate validation with a governance-shaped gap, not as a threat ranking

- D: The competitor landscape now frames the benchmark around the April 2026 category event -
  Karpathy's llm-wiki pattern (98.5, a gist not a product) and Garry Tan's gbrain (92.9, Markdown +
  typed graph + MCP) - as market validation of Memory Seed's substrate philosophy, with the
  contested ground being what sits on top: the winner was the only system to hallucinate on a
  never-stored question, products failed hardest on updated facts (Zep 8/24), and a top comment
  states the differentiation unprompted ("wins because it's inspectable... the durable memory
  layer isn't recall, it's provenance, an append-only record").
- R: The raw table reads as "four unknowns beat the market" until profiled: the #1 is a pattern
  anyone can adopt, the #1 hosted is a just-launched company with no independent footprint (a
  commenter alleged it was fabricated; verified real), and the two Markdown-native entries carry
  the two most influential names in the space - meaning the bet Memory Seed made before this index
  existed just won it. The weaknesses the author's own data assigns to the winners (fabrication,
  updates, staleness, collaboration) map one-to-one onto Memory Seed's validated write path,
  supersession machinery, and provenance - E8's flawless stale-head navigation and the v2 matrix's
  zero fabricated rationale sit exactly on the losing probes.
- A: Treating gbrain as the primary threat was considered and narrowed: it is the closest shape
  and the biggest distribution, but it has no decision governance, no validated writes, and no
  lifecycle edges - recorded as the neighbour to watch, not the verdict.
- F: `business/market/competitor-landscape.md`, `business/research/field-evidence-log.md` (E9
  addendum).
- T: All four profiles verified by direct fetch/search 2026-08-05, sources linked in the dossier.

#### D2 - Gate any submission behind a pre-registered private dry-run with a kill condition

- D: `docs/2_Todo/memory-index-dry-run-plan.md` designs the six-category approximation on the
  agent-capture machinery (~10 seeding + ~25 quiz sessions, ~$25): benchmark-faithful mechanics
  (agent follows the shipped docs), blind two-stage judging, pre-registered expectations - updated
  facts and false-memory as strengths, arbitrary-fact recall as the expected weakness - and a kill
  condition: score below the published #8 (Zep 75.1) means fix first, do not submit v0.2.
- R: v0.2 lands early September, which converts "never enter a benchmark blind" from principle to
  deadline. Pre-registering the expected weakness matters because the store is decision-shaped by
  design: if direct recall drags the blend down, the honest finding is "adapter needed", and only a
  measured dry-run can distinguish that from "memory is bad" before a public number exists. The
  expectations are written now so the result cannot be read opportunistically - the same
  pattern-over-threshold discipline JNL set for E5/E6.
- A: Submitting immediately on the strength of E8/v2 results was declined - those measure
  decision-governance probes, not their taxonomy, and the benchmark's own mechanics (docs-driven
  end-to-end) mean the score also measures the instruction surface, which has never been quizzed
  this way. Replicating their full 272-probe set was declined on cost; directional with error bars
  suffices for a go/no-go.
