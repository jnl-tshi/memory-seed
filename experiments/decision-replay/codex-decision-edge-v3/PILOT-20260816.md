# Codex decision-edge v3 pilot — 2026-08-16

## Result

The fresh blinded three-subject v3 block produced **zero full semantic-safety passes**. It is an
instrument result only and must not be pooled with the earlier Codex v2 or Claude experiments.

The amended fixture-local runner did remove the v2 Windows validation failure: all three subjects ran
the public command successfully, stayed within the permitted file scope, and returned complete final
evidence. That operational repair does not establish a Memory Seed effect.

## Method

- Run ID: `20260816T235525Z-codex-v3`; one randomized block, three fresh Codex collaboration subjects,
  executed in the public-manifest order.
- Grading and the blinded summary were recorded before the condition map was opened.
- Raw subject final reports, grade JSON, blinded summary, condition map, and revealed result are retained
  locally under the gitignored `f/20260816T235525Z-codex-v3-artifacts/` directory.
- Every candidate passed baseline integrity, bounded scope, `python RUN_TASK_TESTS.py`, and final-report
  completeness.

## Revealed outcomes

| Arm | Visible behavior | Non-projection | Robustness | Candidate-test discriminator | Overall |
| --- | --- | --- | --- | --- | --- |
| No dated memory | pass | fail | pass | pass | fail |
| Historical available | pass | pass | pass | fail | fail |
| Relevant rationale pushed | fail | pass | fail | pass | fail |

The no-memory candidate widened decision edges into entry-level state, violating the key safety rule.
The historical-available candidate passed the hidden semantic oracle but its candidate test raised an
error on pristine source, so it did not satisfy the discriminator. The pushed candidate explicitly
cited the provided decision rationale and avoided projection, but did not implement the visible/focus
or singular-`d1` behavior completely.

## Decision

Do not scale this instrument to 24 subjects and do not claim an effect of preserved rationale. The
block remains useful evidence that the public command and task wording are now operational, but a later
instrument revision should require candidate-authored tests to fail on pristine source through
assertions rather than errors. Separating semantic correctness from test-craftsmanship in analysis is a
proposal for a new protocol, not a retroactive change to this block.
