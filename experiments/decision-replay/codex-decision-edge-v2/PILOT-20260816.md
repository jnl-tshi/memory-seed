## Why this is not a scored result

Two pre-scale defects make causal interpretation inappropriate:

1. `EXPERIMENT_CONTEXT.md` named a plain public unittest command that resolves an incompatible installed
   package in this Windows fixture. Two subjects discovered a local `PYTHONPATH=memory-trace` workaround;
   the external grader already supplied that isolated import path. The subject-facing command must be
   corrected and requalified.
2. The frozen semantic grader required the single-decision `d1` fallback, but `TASK.md` did not state that
   valid `d1` on a single-decision target resolves to its entry row, nor that invalid ordinals on a
   multi-decision target must draw nothing. The supplied D2 rationale concerns non-projection, not that
   fallback, so the miss cannot be attributed to a memory condition.

The observed arm pattern is therefore a useful diagnostic only. It does **not** demonstrate a Memory
Seed effect, lack of effect, retrieval effect, speed effect, or maintainer reconstruction effect.
