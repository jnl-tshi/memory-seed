# Memory Seed business

This area is the maintained source of truth for Memory Seed as a business. It separates commercial
strategy from the product specifications and implementation lifecycle in `docs/`.

## How to use this area

- Treat the dossiers below as living documents: update the canonical file instead of creating a new
  dated report for every research pass.
- Keep sourced facts, competitor claims, and Memory Seed estimates visibly separate.
- Record `last_reviewed`, `next_review_due`, source check dates, assumptions, confidence, unresolved
  questions, and material changes.
- Preserve older research reports beside the dossier they support when they remain useful provenance.
- Do not store credentials, personal data, customer-confidential material, or third-party secrets here.
